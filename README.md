# The Beagle Blog

A simple, single-page project about beagles. It introduces the breed, shares a photo, and rounds things off with a few quick facts.

## Take a look

The page includes:

- A short introduction to beagles
- A photo and a link to find more images
- A numbered list of beagle facts

## View it locally

No installation or build step is needed. Download or clone the project, then open `index.html` in your browser.

## Project files

- `index.html` contains the page content.
- `style.css` controls the layout and appearance.

The page uses the Inter font from Google Fonts and loads its beagle photo from an external image URL, so those need an internet connection to appear.
